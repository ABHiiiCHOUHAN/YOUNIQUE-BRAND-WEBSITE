# Video Assets Directory

Place your video cuts and reels here for the Video Editing showcase (`/work/8`).

### Recommended Formats & Codecs:
- **Formats:** `.mp4`, `.webm`
- **Video Codec:** H.264 (AVC) or AV1/VP9 for maximum web compatibility
- **Audio Codec:** AAC or Opus (stereo, 44.1 kHz or 48 kHz)
- **Aspect Ratios:**
  - `9:16` vertical (1080 × 1920) for vertical reels, TikTok & mobile cuts
  - `16:9` cinematic (1920 × 1080 or 4K 3840 × 2160)
  - `4:5` portrait (1080 × 1350)
- **Max File Size:** Under 15MB recommended for smooth instant web streaming (compress with Handbrake or FFmpeg).

### File Naming Convention:
- `cut-1.mp4`, `cut-2.mp4`, `cut-3.mp4` ...
- Or project named: `commercial-reel.mp4`, `cinematic-color-grade.mp4`, etc.

The Depth Carousel and Thumbnail Reel will automatically detect and play videos placed in this directory.
